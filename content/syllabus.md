# CIS 365 — Full Stack Web Development

*Course Syllabus · Updated 2026*

## Description

This course is an introduction to full stack web application development. Students learn to build complete applications: front-end user interfaces, custom and third-party server-side APIs, server middleware, databases, and the surrounding services (email, authentication, hosting) that a real application depends on.

The course also covers the soft skills of being a developer: requirements gathering, project planning and management, wireframing, documentation, and the everyday habits of working on a team.

Classwork is done using Git, GitHub, Node.js, SQL, Visual Studio Code, npm, and Bootstrap — with additional exposure to Vue.js and lightweight frameworks like Alpine.js.

## Course Learning Objectives

Upon completing this course, students will be able to:

- Describe the basic elements of enterprise application design.
- Employ effective requirements-gathering techniques.
- Design and build a full stack web application.
- Converse fluently on the key technologies used in full stack careers.
- Select and apply the right technology for a given project's requirements.

Along the way, students build hands-on comfort with VS Code, Git, command-line basics, and modern front-end frameworks.

## Technology Requirements

All coursework can be completed in the browser using GitHub's free Codespaces environment — no local software installation is required, though students are welcome to work locally in VS Code if they prefer. Students will need a web browser, a free GitHub account, and access to video conferencing software for live sessions.

## Suggested Additional Resources

No textbook is required. Students who'd like to get a head start or go deeper between sessions may find these free resources helpful:

- [MDN Web Docs](https://developer.mozilla.org/) — the standard reference for HTML, CSS, and JavaScript.
- [freeCodeCamp](https://www.freecodecamp.org/) — free, self-paced full stack curriculum with hands-on projects.
- [The Odin Project](https://www.theodinproject.com/) — a free, project-based full stack curriculum.

## A Note on This Course

This course was originally developed for students at a seminary-affiliated program in Baltimore, and has been updated to reflect current tools and the current job market. The spirit of the original course — hands-on, conversational, and unafraid of "we'll figure it out together" — carries through in this format too.
